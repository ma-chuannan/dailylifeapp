# PC 使用信息记录系统 — 设计文档

## 1. 项目概述

**项目名称：** PC Usage Tracker
**项目类型：** Flutter Windows 桌面应用（独立项目）
**核心功能：** 后台运行，记录电脑使用信息（开机时长、应用使用时长、键盘敲击次数等），支持久坐/超时提醒
**目标用户：** 希望复盘个人电脑使用习惯、关注健康（久坐问题）的用户

## 2. 技术栈

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 框架 | Flutter Windows | 与 dailylifeapp 保持一致 |
| 系统 API | `win32` 包 | 调用 Windows API 获取前台窗口、键盘事件 |
| 数据存储 | SQLite (`drift`) | 本地离线优先，轻量 |
| 系统托盘 | `system_tray` | 最小化到托盘，后台运行 |
| 后台运行 | 最小化托盘 + 开机自启 | 用户登录后自动启动 |

## 3. 记录数据项

| 类别 | 字段 | 说明 |
|------|------|------|
| 会话信息 | `session_id`, `start_time`, `end_time`, `duration_minutes` | 每次开机到关机为一个 session |
| 应用使用 | `app_name`, `window_title`, `duration_minutes`, `date` | 按前台窗口聚合使用时长 |
| 键盘 | `keystroke_count`, `date`, `session_id` | 累计敲击次数 |
| 空闲检测 | `idle_start`, `idle_end`, `idle_minutes` | 无操作时段 |

## 4. 提醒功能

| 层级 | 触发条件 | 提示内容 |
|------|----------|----------|
| 久坐提醒 | 连续使用 45 分钟 | "你已连续使用电脑 45 分钟，建议站起来活动一下" |
| 超时提醒 | 连续使用 2 小时 | "你已使用电脑超过 2 小时，记得适当休息" |

提醒以系统通知或托盘气泡形式呈现。

## 5. 数据存储

- **SQLite 本地数据库**，文件保存在用户数据目录下
- 每日/每周自动汇总统计数据
- 数据完全本地存储，不上传（与 dailylifeapp 分离独立）

## 6. 应用行为

- **开机自启**：用户登录后自动在后台启动
- **最小化托盘**：关闭主窗口时最小化到系统托盘，而非退出
- **托盘菜单**：显示/隐藏主窗口、查看今日统计、退出应用
