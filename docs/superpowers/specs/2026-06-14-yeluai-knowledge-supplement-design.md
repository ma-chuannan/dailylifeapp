## 4. 抽取规则

**保留：**
- 概念定义、原理机制、趋势研判、选型逻辑
- 参数建议值（如"客服场景相似度阈值 0.75-0.8"）
- 设计框架（CRAFT）、方法论表格、对比表（如"AI 智能体 vs 人类学习方式"）
- 名词解释

**丢弃：**
- 操作步骤（"点击 X 按钮"、"输入 API Key"、"保存发布"）
- UI 截图说明、字段表、配置项枚举
- 思考题、作业题、本章问题
- 与 YeLuAI 平台无明确映射的纯营销案例
- docx 独有的"营销飞轮"——作为 01 章下"营销场景"小补充，不做独立章节

**统一处理：**
- 术语统一："智能体"统一不写"AI Agent"等并列
- 同一概念两素材都出现时取表述更精炼的，末尾标 "(参见 docx 第 X 章 / pptx2 第 X 章)"
- 保留可执行的参数建议值（如温度 0~0.2 适合客服），这些是"知识性"而非操作

## 6. 实现方式

**工具**：python `python-docx` 库
**脚本**：`C:\Users\16288\Desktop\yeluai_extract\build_supp_docx.py`
